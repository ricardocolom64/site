# Site

My website showcasing projects and work experience.

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) (React 19, TypeScript)
- **Styling**: Tailwind CSS 4
- **Build Tool**: Vite

Every page is prerendered to static HTML at build time.

## Getting Started

### Prerequisites

- Node.js 24 (`nvm use` picks it up from `.nvmrc`)

### Installation

```bash
npm install
```

### Running the Development Server

```bash
npm run dev      # http://localhost:3000
```

### Building

```bash
npm run build    # static output in dist/client
npm run preview
```

## Project Structure

- `src/routes/` - File-based routes only. `__root.tsx` is the HTML shell, and `projects/route.tsx` is the shared project layout.
- `src/components/`, `src/layouts/` - React components
- `src/router.tsx` - Router setup, and the types for per-route `staticData` (`hideHeader`, `project`)
- `src/routeTree.gen.ts` - Generated by the router plugin. Don't edit it.
- `public/` - Static assets served as-is

## Deployment

The site is hosted on a VPS, where [Caddy](https://caddyserver.com) serves the static build from `/var/www/vhosts/site/current` and handles HTTPS. The Caddy config lives in the separate VPS config repo.

Deploys are manual and only run from `main`:

1. Merge your changes into `main`.
2. In GitHub, open **Actions → Deploy to VPS → Run workflow** and run it on `main`.

The [workflow](.github/workflows/deploy.yml) typechecks and builds the site, uploads `dist/client/` to a new `releases/<timestamp>-<sha>/` folder on the server, then switches the `current` symlink to it atomically. The 5 newest releases are kept.

### Secrets

| Secret | Value |
| --- | --- |
| `SERVER_HOST` | The VPS hostname or IP |
| `SERVER_USER` | The SSH user that owns `/var/www/vhosts/site` |
| `SERVER_SSH_KEY` | That user's private SSH key |
| `SERVER_KNOWN_HOSTS` | The server's host key line, from `ssh-keyscan -t ed25519 <host>` |

### Rolling back

Point `current` back at an earlier release on the server:

```bash
cd /var/www/vhosts/site
ls -1t releases/                                # newest first
ln -sfn "$PWD/releases/<release>" current.next && mv -Tf current.next current
```
